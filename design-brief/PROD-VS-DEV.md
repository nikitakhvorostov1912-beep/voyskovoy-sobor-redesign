## 4. Стилистическая близость

| Параметр | Прод | Dev |
|---|---|---|
| Палитра | Тёмно-синий header `#3b6396`, белый фон, серый текст | Тёмно-синий `#1a1a2e`, золото `#c9a961`, кремовый `#faf8f5`, бордовый `#8b2635` |
| Типографика | Sans-serif (видимо Open Sans / Arial), без serif-заголовков | Cormorant Garamond + Playfair Display + Ruslan Display + Inter |
| Иконо-баннер | Используется на всех страницах | Нет, есть только слайдер на главной |
| Декор | Минимальный | `gold-shine`, `ornament-divider`, scroll-reveal анимации |
| Иконки | Стандартные WP-стрелочки, JPG | Emoji `🕊️ ✝️ 💛 📰 ⚔️ 🙏 🎵` |

**Вывод:** dev — амбициозный редизайн, но он **проигрывает проду в идентичности**. Сейчас на проде узнаваемый православный иконо-баннер, который привязан к конкретному собору. В dev этого нет — там только эмодзи-fallback.

## 5. Что это значит для дизайн-задачи

### Опция A — продолжить редизайн в dev и в перспективе заменить прод
Это и предполагалось изначально. Тогда верны все 25 задач из [TASKS.md](TASKS.md), но с дополнениями:
- **T-26 (новая):** интегрировать иконо-баннер с проды как один из вариантов hero (скачать `assets/images/header-banner.jpg` и встроить как fallback или в специальный режим).
- **T-27 (новая):** настроить URL-redirects с латинских slug'ов на кириллические (или наоборот) — чтобы старые ссылки (закладки прихожан, поисковики) не сломались.
- **T-28 (новая):** мигрировать данные: новости из `/category/новости/` в новый CPT `church_news`, духовенство из `/category/персоналии-собора/` в новый CPT, история из `/category/летопись-собора/` тоже.
- **T-29 (новая):** интегрировать GiveWP вместо самописной формы пожертвований ИЛИ убрать GiveWP и переключиться на свою. Решение зависит от того, есть ли там накопленная статистика донатов.
- **T-30 (новая):** скачать с проды все картинки/медиа (включая JPG с расписанием), мигрировать в media library.

### Опция B — улучшить текущий прод-сайт без редизайна
Если задача не "переехать на Kadence", а просто "сделать сайт лучше":
- Не трогать тему. Поработать с CSS-overrides через child-theme или Customizer.
- Заменить JPG-расписание на структурированную таблицу (custom widget или редактор).
- Улучшить мобильное меню (на скриншотах оно ломает вёрстку — текст hero стоит на меню).
- Адаптивный sidebar — на мобиле он сейчас уходит вниз, можно сделать компактным.
- Кастомный 404 с навигацией.

### Опция C — гибрид
Продолжить dev-тему, но скопировать с проды самое узнаваемое — иконо-баннер. Сделать его как один из вариантов hero. Сохранить золотую палитру dev, но добавить вариативность.

## 6. Чего я не знаю и нужно уточнить

1. **Решение между A/B/C** — что считается "доработкой" в задаче?
2. **GiveWP** — реальный плагин с настроенным платежным шлюзом или тестовый? Если работает — должен ли остаться?
3. **Старая тема прода** — какая именно? Можно посмотреть в `view-source` или из админки. Это влияет на порядок миграции.
4. **Доступ к админке прода** — есть ли пароль / можно ли смотреть activity / настройки? Без этого мигрировать данные будет вслепую.
5. **Когда планируется выкатывать dev в прод** — это разовая большая миграция или постепенная?
6. **Storage кириллических медиа** — в `wp-content/uploads` могут быть тяжёлые JPG/PNG для иконо-баннера. Их нужно мигрировать тоже.
