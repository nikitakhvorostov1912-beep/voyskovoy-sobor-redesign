## 5. Стилистические референсы

- **Палитра соответствует** православной традиции (синий/золото/бордо/кремовый) — НЕ ломать. Можно осовременить акценты.
- Не уходить в «глянец» — храм древний, нужен сдержанный, литургичный, благородный вид.
- Допустимо: золочёные орнаменты (тонко), византийские мозаичные паттерны (только декор), фрески как hero-фоны (с тёмным градиентом-оверлеем).
- Недопустимо: emoji в production UI, мультяшные иконки, неоновые градиенты, glassmorphism, кричащий золотой блеск.

## 6. Жёсткие ограничения

- **НЕ ломать backend:** все CPT, AJAX-эндпоинты, Customizer-секции, шорткоды, walker, мета-боксы, Telegram/Email/YooKassa-логика остаются. Это work-in-progress production сайт.
- **НЕ ломать URL-схему:** `/services`, `/news`, `/history-archive`, `/services` оставить как есть (rewrite slugs прибиты в CPT, у пользователей в закладках).
- **НЕ менять `Template: kadence`** — Kadence parent остаётся, child только переопределяет.
- **Кастомизация через Customizer** — приоритет над хардкодом. Если добавляешь новый блок — выноси настройки в Customizer.
- **Все строки на русском.** UI, alt-теги, aria-label, всё. Текст в коде не латинизировать.
- **Совместимость с WordPress 6.x + PHP 8.0+.**
- **Безопасность:** AJAX уже использует nonce, но проверить новые формы — `wp_verify_nonce`, `current_user_can`, экранирование вывода (`esc_html`, `esc_url`, `esc_attr`).
- **Маркеры в правках:** при изменении существующего файла (не нового) оборачивать блок:
  ```php
  // Доработка START {short-task} {2026-05-05}
  …новый код…
  // Доработка END
  ```
