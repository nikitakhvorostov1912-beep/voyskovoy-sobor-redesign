## 1. Optina.ru — главный донор эстетики

📁 [`references/church-sites/optina.png`](references/church-sites/optina.png)

**Что берём:**
- **Hero-баннер** — сепия-литография панорамы (для Войскового — фотопанорама собора + золотой overlay)
- **Sigil справа** — круглая иконка с орнаментальной рамкой (для Войскового — герб войска или икона князя в круге)
- **Левая навигация** — жёсткая колонка категорий, узкая, без лишнего; контент справа двух-колоночно
- **Цитата как центральный элемент** — изречение Священного Писания / святого, с подписью; serif, центрированное, с золотой подписью автора
- **Чёрно-белая фотография** старца в карточке («Варсонофий») — переносим: фото настоятеля + биография в той же стилистике
- **Тон** — монашеский, тихий, исторический, не торопливый

**Что НЕ берём:**
- Архаичный шрифт интерфейса (у нас должен быть читаемый)
- Слишком зажатую вёрстку (у нас простор)

## Итоговый стиль для Войскового собора Александра Невского

**Концепция: «Литургическая монументальность»**

Гибрид:
- **70% Optina** (тон, история, тишина, сепия-фотографии, классическая русская типографика)
- **20% OCA** (структура, иерархия, надёжная синяя шапка с гербом)
- **10% Holy Trinity** (портретные фото героики, монохром + цветные плашки-даты)

С добавлением **войскового аспекта** (это собор казачьего войска):
- Двуглавый орёл (sigil или favicon)
- Тонкие декоративные элементы военной геральдики (шеврон, лавровая ветвь)
- НО без перегиба в милитаризм — это собор, не музей войны

## Палитра (финал)

```css
:root {
  /* Основа — фон и текст */
  --color-paper:        #f5f0e8;  /* пергамент / кремовый — основной фон */
  --color-paper-dark:   #ebe3d4;  /* углубление, для альтернативных секций */
  --color-ink:          #1a1f2e;  /* почти чёрный с синим оттенком — основной текст и шапка */
  --color-ink-soft:     #2d3548;  /* приглушённый */
  --color-text:         #2a2620;  /* тёмно-коричневый, для длинного чтения по серьёзному */
  --color-text-muted:   #6b5f4f;  /* сепия-приглушённый */

  /* Акценты — литургические */
  --color-gold:         #c9a961;  /* золото иконы / парчи — для CTA, акцентов, ссылок */
  --color-gold-dark:    #9c7c3a;  /* hover-золото */
  --color-gold-pale:    #e8d8a8;  /* soft золото для бэкграундов карточек */

  /* Спец-цвета */
  --color-blood:        #8b2635;  /* мученическая кровь / Страстная — donate, важные акценты */
  --color-blood-dark:   #6b1c28;
  --color-shadow:       #00000014;

  /* Легенда */
  /* Гербовая палитра войска не используется в UI напрямую */
  /* — оставлена для иллюстраций / иконок */
}
```

**Ключевая разница с текущей dev-палитрой:**
- Заменили `#1a1a2e` → `#1a1f2e` (теплее)
- Заменили `#faf8f5` → `#f5f0e8` (больше пергамент, меньше «офисный»)
- Текст `#2d2d2d` → `#2a2620` (с тёплым подтоном)
- Добавили `--color-paper-dark`, `--color-gold-pale`, `--color-shadow`

## Типографика (финал)

```css
:root {
  /* Display — для главных заголовков и hero */
  --font-display: 'Cormorant Garamond', 'Spectral', 'PT Serif', serif;

  /* Decorative — особо торжественные надписи (название собора, обращения) */
  --font-decor:   'Ruslan Display', 'Cormorant Garamond', serif;

  /* Body — длинное чтение, статьи, новости */
  --font-body:    'Spectral', 'PT Serif', 'Lora', Georgia, serif;

  /* UI — кнопки, навигация, формы, метаданные */
  --font-ui:      'PT Sans', 'Inter', system-ui, sans-serif;

  /* Numerals — даты, расписание, цены */
  --font-numeric: 'Spectral', tabular-nums;
}
```

**Почему Spectral для body, а не Inter:**
- Inter — корпоративный sans, не подходит для длинных молитвенных/исторических текстов
- Spectral — современный slab-serif, открытый для long-read, имеет отличную кириллицу, бесплатный (Google Fonts)
- Для смешанной читаемости на мобильном можно сохранить Inter в `--font-ui` для UI-элементов

**Размеры (responsive):**
```css
:root {
  --text-xs:   clamp(0.75rem,  0.7rem + 0.2vw, 0.875rem);
  --text-sm:   clamp(0.875rem, 0.85rem + 0.2vw, 1rem);
  --text-base: clamp(1rem,     0.95rem + 0.3vw, 1.125rem);
  --text-lg:   clamp(1.25rem,  1.15rem + 0.5vw, 1.5rem);
  --text-xl:   clamp(1.5rem,   1.4rem + 0.6vw, 1.875rem);
  --text-2xl:  clamp(2rem,     1.8rem + 1vw,   2.5rem);
  --text-3xl:  clamp(2.5rem,   2.2rem + 1.5vw, 3.5rem);
  --text-4xl:  clamp(3rem,     2.5rem + 2vw,   4.5rem);  /* hero */
  --text-display: clamp(3.5rem, 3rem + 2.5vw,  5.5rem);  /* особо */
}
```

## Декор-элементы (визуальные сигналы храма)

1. **Ornament-divider** — SVG-крест с виноградной лозой (ширина 200-280px, высота 32px), цвет `--color-gold`. Используется как разделитель между секциями вместо `<hr>`.

2. **Drop-cap** в больших текстах (статьи, проповеди) — первая буква параграфа набором display-шрифта в 4× размер, с золотой обводкой.

3. **Gold-leaf border** — тонкая золотая рамка (1-2px solid `--color-gold-pale`) на специальных карточках (память святых, важные объявления). НЕ на всех — иначе теряет силу.

4. **Vintage-photo overlay** — для исторических фото добавлять лёгкое sepia-tint (CSS `filter: sepia(15%) contrast(1.05)`), еле заметно, чтобы фотография «жила» в общем тоне.

5. **Sigil — двуглавый орёл войска** — SVG, монохром, использовать как favicon, в шапке, на 404-странице, в footer'е. НЕ в hero (там икона).

6. **Грифельная доска** — фон `--color-ink` с лёгкой текстурой шума `noise.svg`, для тёмных секций (расписание, архив, подвал).

7. **Параллакс-баннер** — иконо-баннер с проды (если разрешат — скачать) с лёгким translate-y при scroll. Hero только на главной, на остальных страницах — чистая шапка с logo+nav.

## Anti-patterns (так точно НЕ делать)

- ❌ Emoji в production UI (🕊️ ✝️ 💛 ⚔️) — только настоящие иконки
- ❌ Inline-стили в шаблонах
- ❌ Пастельные градиенты Apple-стиля — для собора неуместно
- ❌ Glassmorphism / Neumorphism — слишком trendy, устареет за 2 года
- ❌ Параллаксы повсеместно — только в hero, не в каждой секции
- ❌ AOS-style scroll-reveal на каждой карточке — отвлекает от чтения
- ❌ Hover-эффекты с rotate / 3D-flip — это не shop, это собор
- ❌ Видео-фон с автозвуком (только muted и opt-in)
- ❌ Псевдо-литургические шрифты (Old English, Готика) — не наша традиция, у нас русское православие
- ❌ Тёмная тема как первичная — для собора светлая (пергамент) исторически точна
