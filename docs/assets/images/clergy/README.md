# Фото клириков — инструкция

## Пустая рамка-шаблон

- **`_template-empty-frame.png`** — 600 × 750 px (книжная 4:5)
- **`_template-empty-frame@2x.png`** — 1200 × 1500 px (Retina)

Цвета шаблона повторяют рамку с архивными фото на странице «История»:
- внешний тёмно-синий кант `#1a1f2e`
- внутренняя золотая обводка `#c9a961`
- белая зона для фото

## Что делать с фото батюшек

1. Открыть `_template-empty-frame@2x.png` в Photoshop / Canva / любом редакторе.
2. Вставить портретное фото священнослужителя поверх белой зоны (внутри золотой обводки).
3. Кадрировать так, чтобы лицо было в верхней трети, плечи — у нижней границы.
4. Сохранить готовый файл с именем по образцу: `kadurov.jpg`, `feer.jpg`, `popov.jpg`, `klochkov.jpg` (заменить существующий).
5. Финальный размер: **1200 × 1500 px**, JPG, качество 85 %.

## Соотношение сторон

Сейчас на странице `clergy.html` карточки квадратные (140 × 140 px), но рамка-шаблон в пропорции 4:5 — это правильно для будущей миграции на вертикальные карточки. Если оставить квадратные — можно кадрировать готовое фото в квадрат при экспорте.
