# Тексты для вставки в WordPress-админку

После активации темы и создания 11 страниц (см. README.md → Шаг 2) **поле «Содержимое» можно оставить пустым** — весь HTML уже захардкожен в шаблонах `page-templates/page-{slug}.php`.

Однако WordPress требует, чтобы у каждой страницы был хотя бы заголовок и (опционально) excerpt для SEO. Ниже — готовые **заголовки**, **slug**, **excerpts** (мета-описания) и **первый абзац** для редактора Gutenberg на случай, если вы хотите вынести вступление в `the_content()`.

## Настройка через WP-CLI (быстрый путь)

Если у вас доступ к терминалу хостинга:

```bash
cd /var/www/html  # или путь до WP

# 1. Активация темы
wp theme activate voiskovoy-sobor

# 2. Создание страниц с slug + Page Template
declare -A pages=(
  ["about"]="О соборе"
  ["history"]="История"
  ["schedule"]="Расписание богослужений"
  ["prayer-requests"]="Заказ треб"
  ["clergy"]="Духовенство"
  ["parish-life"]="Приходская жизнь"
  ["icons"]="Святыни и иконы"
  ["news"]="Новости"
  ["contacts"]="Контакты"
  ["donate"]="Пожертвование"
  ["privacy"]="Положение о персональных данных"
)

for slug in "${!pages[@]}"; do
  title="${pages[$slug]}"
  ID=$(wp post create --post_type=page --post_title="$title" --post_name="$slug" --post_status=publish --porcelain)
  wp post meta update $ID _wp_page_template "page-templates/page-$slug.php"
  echo "  ✓ $slug (ID=$ID)"
done

# 3. Главная — отдельно
HOME_ID=$(wp post create --post_type=page --post_title="Главная" --post_name="home" --post_status=publish --porcelain)
wp option update show_on_front 'page'
wp option update page_on_front $HOME_ID

# 4. Постоянные ссылки
wp option update permalink_structure '/%postname%/'
wp rewrite flush --hard
```

## Если хочется редактировать тексты в Gutenberg

Тогда нужна Задача 4 из `NEXT-SESSION-PROMPT.md` — вынести контент из PHP в `post_content`. После этого вы сможете редактировать **тексты** «О соборе», «Истории» и т.д. через визуальный редактор. **Структура** (hero, ribbon, footer-cta) останется в шаблоне.
