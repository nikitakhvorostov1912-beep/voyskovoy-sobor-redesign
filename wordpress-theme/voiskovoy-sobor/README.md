# WordPress тема — Войсковой Собор Александра Невского

Тема для официального сайта Войскового собора святого благоверного князя Александра Невского в Краснодаре. Сгенерирована из статичного сайта `docs/` (12 HTML страниц + 404).

---

## Установка темы в WordPress

### Шаг 1. Загрузить ZIP

1. WP-админка → **Внешний вид → Темы → Добавить новую → Загрузить тему**
2. Выберите файл `voiskovoy-sobor.zip` (один уровень выше)
3. Нажмите **Установить → Активировать**

После активации сайт встанет на место — header, footer, Schema.org JSON-LD, шрифты, CSS — всё подключится автоматически.

### Шаг 2. Создать страницы

В WP-админке → **Страницы → Добавить новую**. Нужно создать 11 страниц с указанными ниже **slug** и **Шаблоном страницы**. Можно делать через CLI WP-CLI или вручную.

| № | Заголовок | Slug (URL) | Page Template (выбрать в правой панели «Атрибуты страницы») |
|---|---|---|---|
| 1 | О соборе | `about` | **О соборе** |
| 2 | История | `history` | **История** |
| 3 | Расписание богослужений | `schedule` | **Расписание богослужений** |
| 4 | Заказ треб | `prayer-requests` | **Заказ треб** |
| 5 | Духовенство | `clergy` | **Духовенство** |
| 6 | Приходская жизнь | `parish-life` | **Приходская жизнь** |
| 7 | Святыни и иконы | `icons` | **Святыни и иконы** |
| 8 | Новости | `news` | **Новости** |
| 9 | Контакты | `contacts` | **Контакты** |
| 10 | Пожертвование | `donate` | **Пожертвование** |
| 11 | Положение о персональных данных | `privacy` | **Положение о персональных данных** |

> **Важно**: контент берётся из шаблона (PHP). Поле «Содержимое» страницы можно оставить пустым — текст уже захардкожен в `page-templates/page-{slug}.php`. Если в будущем нужно вынести контент в Gutenberg-редактор — см. NEXT-SESSION-PROMPT.md.

### Шаг 3. Настроить главную страницу

WP-админка → **Настройки → Чтение**:
- На главной странице отображать → **Статическую страницу**
- Главная страница → создать новую страницу с заголовком **Главная** (slug `home` или любой, не важно — front-page.php перехватит вывод)
- Страница записей → создать страницу **Блог** (если планируется блог) или оставить пустым

### Шаг 4. Назначить меню

WP-админка → **Внешний вид → Меню**:

1. Создать меню «**Главное меню**» с пунктами в порядке:
   Главная · О соборе · История · Расписание · Заказ треб · Духовенство · Приход · Святыни · Новости · Контакты
2. Назначить как **Главное меню (шапка)** + **Мобильное меню (drawer)**
3. (опц.) Создать меню **Меню в подвале** — оно отображается в `usite-footer__col`-ах, но для них уже есть hardcoded fallback

Если меню не настроено — тема выводит default-меню (10 пунктов как на статичной версии).

### Шаг 5. Постоянные ссылки

WP-админка → **Настройки → Постоянные ссылки** → **Название записи** (`/%postname%/`).

Это нужно, чтобы URL-ы соответствовали slug-ам (`example.com/about`, `example.com/schedule` и т.д.).

## Что внутри темы

```
voiskovoy-sobor/
├── style.css                ← заголовок темы (обязательный для WP)
├── functions.php            ← enqueue стилей/скриптов, регистрация меню, Schema.org JSON-LD
├── header.php               ← <head> + <header class="uheader"> + skip-link
├── footer.php               ← usite-footer + mobile drawer + wp_footer()
├── index.php                ← fallback-шаблон (lista записей)
├── 404.php                  ← страница «не найдено»
├── page.php                 ← общий шаблон страниц
├── front-page.php           ← главная (контент из docs/index.html)
├── page-templates/          ← 11 уникальных шаблонов
│   ├── page-about.php
│   ├── page-clergy.php
│   ├── page-contacts.php
│   ├── page-donate.php
│   ├── page-history.php
│   ├── page-icons.php
│   ├── page-news.php
│   ├── page-parish-life.php
│   ├── page-prayer-requests.php
│   ├── page-privacy.php
│   └── page-schedule.php
├── assets/
│   ├── css/site-additions.css
│   ├── js/main.js
│   └── images/

```

## Что осталось доработать (см. NEXT-SESSION-PROMPT.md)

1. **Sidebar widgets** — для блога / новостей
2. **Customizer-настройки** — реквизиты, телефоны, ИНН/ОГРН вынести в Settings API
3. **Custom Post Type «Новости»** — сейчас `news.html` контент захардкожен; для динамического блога нужны `single-post.php` + переделка `news.html` под loop
4. **Gutenberg-блоки** — если приход хочет редактировать контент О соборе / История / Святыни через визуальный редактор, нужно вынести из шаблонов в Gutenberg patterns
5. **ACF (Advanced Custom Fields)** — для контактов, расписания, литургических дат
6. **Comments / форма обратной связи** — currently form uses mailto:, можно переключить на Contact Form 7 / WPForms

## Совместимость

- **WordPress**: 6.0+
- **PHP**: 7.4+
- **Mobile**: hamburger menu при ≤ 1180px
- **A11y**: skip-link, focus-visible, aria-current на active menu, prefers-reduced-motion
- **SEO**: Schema.org Church JSON-LD на всех страницах через `wp_head()`
- **Cache**: рекомендуется WP Super Cache / W3 Total Cache (статичный HTML)
- **Шрифты**: Google Fonts (Cormorant Garamond + Spectral + PT Sans) — могут быть отключены и заменены на self-hosted при необходимости
